CS Operations — Project Tracker

How to Use

📊 Dashboard

Click any project card to view and edit its details. Use filters to narrow by phase.

✏️ Project Details

Select a project to view and edit all information including:

  • Project description and metadata
  • KPIs and success metrics
  • Subtasks with owner and status
  • Decisions and notes
  • Reference documents
  • Working notes (scratch pad)

➕ Adding Items

In the Project Details view, click "Add [Item Type]" buttons to add:

  • Subtasks - Assign to team members, track status
  • KPIs - Track target vs. actual metrics
  • Decisions - Log important decisions with dates
  • References - Link to relevant documents

💾 Data Management

Export: Click "↓ Export" to download all data as JSON

Import: Click "↑ Import" to load previously exported JSON

Sync with team: Export your changes and share the JSON file. Team members can import to get the latest updates.

💡 Tip: All changes save automatically to your browser. Export regularly to Google Drive as backup!
