How to Use the Project Tracker

📊 Dashboard Tab

View all your CS projects at a glance. Each project card shows:

  • Project name — Click the card to view full details
  • Requester — Which team submitted the request
  • Phase badge — Discovery, Building, Reviewing, Blocked, etc.
  • Owner — Who's assigned to lead this project
  • Progress bar — Visual representation of project completion
  • Priority badge — Red flag if this is a priority for the current quarter
  • Due date — Expected completion date

Filters: Use the filter dropdowns to show projects by phase, priority status, or active projects only.

📅 Timeline Tab

Visual Gantt chart showing all projects over time. Each bar represents a project's timeline from start to expected completion. Color represents phase (blue=Discovery, green=Building, orange=Reviewing, red=Blocked).

🔍 Project Details Tab

Select a project from the dropdown to view its complete information including description, KPIs, subtasks, decisions log, and notes.

➕ Adding a New Project

  1. Click the "+ New Project" button in the top toolbar
  2. Fill in the project details:
    • Project Name (required)
    • Phase (Discovery, Building, Reviewing, etc.)
    • Requester (which team requested this)
    • Stakeholder (who oversees it)
    • Owner (who's running it day-to-day)
    • Expected Completion date
    • Priority checkbox (mark if priority for this quarter)
    • Description of the project
  3. Click "Save Project"

✏️ Editing a Project

  1. On the Dashboard, click the "Edit" button on any project card
  2. Update any fields you need to change
  3. Click "Save Project" to apply changes

Note: Subtasks, KPIs, notes, and decisions can be edited by clicking the project to view its full details, then making inline edits (coming in future updates).

💾 Exporting & Importing Data

Export: Click the "↓ Export" button to download all your projects as a JSON file. Perfect for backup or sharing with your team.

Import: Click the "↑ Import" button and select a previously exported JSON file to load projects. Useful for syncing updates from team members.

🖨️ Printing & Sharing

Print: Click the "🖨 Print" button to print the current view or save as PDF in your browser.

Share with Google Drive:

  1. Upload this HTML file to a shared Google Drive folder
  2. Team members can open it directly in their browser
  3. Each person edits their local copy, then exports JSON
  4. Share the exported JSON file to sync changes
  5. Team members import the JSON to get the latest updates

📋 Project Phases Explained

Discovery — Research and scoping phase. Requirements being gathered.

Building/Execution — Active development. Team is actively working.

Reviewing — Solution complete, undergoing review and testing.

Blocked — Waiting on external dependencies or resources.

Pending — Documented but not yet started. In the queue.

Completed — Project finished and closed.

💡 Tips & Best Practices

  • Update phases regularly to keep the tracker current
  • Use the Priority checkbox for Q-specific initiatives only
  • Keep descriptions concise but clear
  • Export monthly backups to Google Drive
  • Use filters to focus on active or blocked projects
  • View the Timeline to spot overlapping projects or resource conflicts

Data Storage: This tracker saves all data locally in your browser. The data is yours and never leaves your computer. Export regularly to Google Drive for backup and team sharing.
